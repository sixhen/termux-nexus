## ⚡ Tổng quan (Overview)

**termux-nexus** là bộ công cụ và hệ sinh thái script tiện ích mở rộng dành cho người dùng Termux chuyên nghiệp, tích hợp sẵn các phím tắt, bí danh (aliases), tối ưu hóa Zsh Powerline và cấu hình mạng nâng cao.

> 🏛️ **Tiêu chuẩn thiết kế:** Tối giản trong tư duy, tinh tế trong cấu trúc, chuẩn xác tuyệt đối trong thực thi. 100% kiến tạo & đồng bộ cùng AI.

---

## 🚀 Các module tích hợp (Modules)

- **⚡ Powerline Theme:** Giao diện dòng lệnh đa màu sắc, hiển thị branch git, pin, mức pin điện thoại và nhiệt độ chip.
- **🛡️ Server Quick-Launch:** Khởi động nhanh máy chủ SSH, FTP, Python Web Server chỉ bằng 1 từ khóa ngắn.
- **🔧 Dọn dẹp & Tối ưu:** Script tự động dọn cache pkg, giải phóng bộ nhớ RAM và dọn rác hệ thống.
- **📦 Batch Installer:** Cài đặt nhanh bộ công cụ phát triển phổ biến chỉ trong 1 lệnh duy nhất.
